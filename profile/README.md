## How Sequence Generator Pro Sits

Sequence Generator Pro does not replace the mount, the camera, or the planetarium you already use. It sits beside them as a named observatory desk for one job: which imaging sequence is live, which equipment profile still matches, and what the next person should read. A local Sequence Generator Pro profile is enough for everyday work on gear you own.

If two people share the observatory PC, each keeps a Sequence Generator Pro style of their own. The live event list stays small on purpose. Extra targets wait for their own sequence instead of crowding the night run.

A first visit should be one short sequence, then the same Sequence Generator Pro desk the next night. That is enough to see if the layout holds.

A night of frames should run as a named sequence, not as a pile of manual shots. Keep Sequence Generator Pro imaging sequence titled before dusk.

Equipment profile is the map of gear you own. Do not start Sequence Generator Pro night run on a profile from another rig.

Park, autofocus, and filter changes belong in the sequence, not in a sidebar note that nobody reads at 2 a.m.

When the sequence ends, leave Sequence Generator Pro observatory desk with a handoff, not with a silent abort.

## Open Order

1. Open the last Sequence Generator Pro sequence, not a new empty observatory desk.
2. Read the event list and the last handoff.
3. Finish one visible step inside Sequence Generator Pro.
4. Write what changed, then close with fewer loose events than you found.
5. If the set feels crowded, drop anything that belongs to a different Sequence Generator Pro job.
6. Confirm Sequence Generator Pro equipment profile matches the rig you own tonight.
7. Load Sequence Generator Pro imaging sequence before you connect cameras.
8. Keep Sequence Generator Pro night run on one target path at a time.
9. Place flats and darks as named events, not as afterthought folders.
10. Leave the sequence title on the desk before you walk away from the mount.
11. Note abort reasons in the handoff while they are still on screen.
12. Copy the night log beside the frames for the next person.
13. If weather parked the run, keep the same sequence for the next clear night.
14. Recheck connections after a restart before first light.

## After a Week

A week in Sequence Generator Pro is not a longer event pile. It is the same title, a shorter live plan, and a note that still makes sense on the next clear night. If every target is live, nothing stands out. Take finished sequences off the live set so the next visit starts on the night run that is still open.

Other programs stay where they are. Sequence Generator Pro only keeps the path back: sequence name, equipment profile, night run, handoff.

Leave Sequence Generator Pro with a quieter observatory desk than the one you opened. The next visit should start on that sequence, not in a pile of manual shots.

If the profile and the connected gear disagree, stop. Fix Sequence Generator Pro equipment profile before first light.

A named imaging sequence is the difference between a plan and a scramble. Keep the title when weather parks the mount.

Abort text belongs in the handoff. The next person should not reconstruct the night from filenames alone.

Continue a multi-night target in the same Sequence Generator Pro imaging sequence. Do not invent a twin plan with a new untitled file.

## Field Note

Sequence Generator Pro is easier to trust when the observatory desk stays smaller than the frame pile it came from. Name the sequence, keep the live plan, finish one visible event, and write what changed. Extra targets wait for their own title.

The same loop fits a backyard rig, a remote shed, or a shared observatory PC. Open the last Sequence Generator Pro sequence and continue. Do not rebuild the layout from scratch.

A night run is a map of events on gear you own. Leave Sequence Generator Pro pointed at that map, with a profile a second person can read.

If the sky closes, park the title. The next clear night should open the same Sequence Generator Pro observatory desk.
